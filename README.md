# DumbPairVerse

DumbPairVerse is a small, beginner-friendly website that brings together 24 characters from books, films, TV, comics, and video games, with six characters in each of four genres. Choose a genre to discover one of its 15 possible duos, pick a scene, and save pairings you like.

## Run it

Open `index.html` in a browser. No installation or build step is needed.

Every character has their own Showdown and Hangout beats, so each pairing's scene reflects both characters' abilities and habits. Nonverbal characters communicate through chirps, beeps, or gestures; the Demogorgon growls rather than speaking. Choose **Surprise me** to switch scenes. The site loads character pictures from their story wikis; if a wiki has no picture, an illustrated avatar appears instead. Wiki buttons link to more information. Character photos need an internet connection.

## Publish with GitHub Pages

1. Sign in at [github.com](https://github.com/) and create a **public** repository named `pairverse`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
5. After GitHub finishes publishing, your site link will look like `https://YOUR-USERNAME.github.io/pairverse/`; the repository link will be `https://github.com/YOUR-USERNAME/pairverse`.
